# Release roadmap

## 0.1 foundation (prepared)

- Shared integrated renderer, printable A4 PDF, embedded SVG and enlarged proofs.
- Original demo that runs without copyrighted game artwork.
- Existing 18 collection recipes preserved.
- Worldwide candidate metadata with provenance and regional/language fields.
- Contribution rules, CI checks and explicit license boundaries.

## 0.2 catalog review

- Confirm original commercial cartridge scope; distinguish iQue and 64DD.
- Map Japanese/localized aliases to the same underlying game without discarding regional labels.
- Deduplicate language/ROM revision entries against packaging evidence.
- Match the 18 existing recipes to verified catalog IDs.
- Record per-asset source and rights data for those recipes.
- Test physical 63 × 16 mm fit on representative cartridges.

## 0.3 USA set

- Produce labels in small reviewed batches, preserving the approved visual standard.
- Review every logo/title and art crop at actual size and enlarged size.
- Release printable PDFs only with an appropriate basis for distributing embedded artwork.

## 0.4 worldwide variants

- Japanese, European and other regional retail editions, with the same quality gate.
- Avoid duplicating identical visual packaging merely because ROM metadata differs.

## Later

- US Letter, optional bleed, printer calibration page and collection selector.
- Web gallery showing preview, region, readiness and downloads.
- Optional homebrew/aftermarket collections, separately scoped.

Completion requires a reviewed retail checklist, artwork provenance, individual visual review and recorded print tests. The current 867 candidates are a backlog, not a verified number of games or finished labels.
